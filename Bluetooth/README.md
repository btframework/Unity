# Bluetooth Framework — Unity Examples

Examples of using [Bluetooth Framework](https://www.btframework.com/bluetoothframework.htm) with Unity.

| Folder | Description |
|---|---|
| `AudioReceiver/` | Bluetooth A2DP audio receiver |
| `AudioSwitcher/` | Audio endpoint management |
| `AudioVolume/` | Audio volume and meter |
| `Beacons/` | BLE beacon watcher and LE advertiser |
| `BleSniffer/` | BLE traffic sniffer |
| `BluetoothManager/` | Classic + BLE manager |
| `FtpClient/` | OBEX FTP client |
| `GattClient/` | GATT client |
| `GattServer/` | GATT server |
| `OppClient/` | OBEX ObjectPush client |
| `OppServer/` | OBEX ObjectPush server |
| `RfCommClient/` | RFCOMM/SPP client |
| `RfCommServer/` | RFCOMM/SPP server |
| `WiiRemote/` | Wii Remote client |

## Building a scene

Each project ships without a prebuilt scene. Use the **Tools** menu in Unity to
generate the UI — the exact menu path is listed in each project's README.
