# WiFiDirectSoftAP — Unity Demo

A Unity example demonstrating the use of the **Wi-Fi Framework** (`wclWiFiSoftAP` class) for starting a Wi-Fi Direct legacy Soft AP, monitoring connected devices, and configuring the Soft AP's IP settings.

This demo is a Unity port of the reference **WiFi Direct Legacy Soft AP** sample shipped with the Wi-Fi Framework.

---

## Overview

The WiFiDirectSoftAP demo starts a legacy Soft Access Point with the SSID and passphrase entered in the UI. Connected devices are accepted individually and their connection / disconnection events are logged together with their local and remote IP addresses. The demo also exercises the Soft AP's IP configuration: it can read the current settings, apply a static configuration, and reset the configuration back to the framework defaults.

The user interface is generated programmatically by an editor script. There are no hand-authored scenes or prefabs to maintain.

---

## Features demonstrated

| Area | `wclWiFiSoftAP` API used |
|------|----------------------------|
| Lifecycle | `Start(ssid, passphrase)`, `Stop`, `OnStarted`, `OnStopped` |
| Device acceptance | `OnDeviceAccept` (`out bool Accept`) |
| Device events | `OnDeviceConnected`, `OnDeviceDisconnected`, `OnDeviceConnectError` |
| Soft AP properties | `GetSsid`, `GetPassphrase` |
| IP configuration | `GetIpSettings`, `SetIpSettings`, `ResetIpSettings` |
| Device info | `wclWiFiDirectDevice.Id`, `Name`, `LocalAddress`, `RemoteAddress` |

## Getting started

### 1. Install the Wi-Fi Framework

Ensure that the framework assemblies (`wclCommon`, `wclWiFi`, and their dependencies) are present in the Unity project and are referenced by the assembly that contains `WiFiDirectSoftAPController.cs`.

### 2. Build the demo scene

From the Unity menu select:

> **Tools → WiFiDirectSoftAP → Build Scene**

This creates the canvas, all controls, the `WiFiDirectSoftAPController` GameObject, and saves the scene to `Assets/Scenes/WiFiDirectSoftAP.unity`.

### 3. Run the scene

Enter Play mode, enter an SSID and passphrase, and click **Start**. The Soft AP starts, `OnStarted` fires, and the log shows the actual SSID and passphrase as reported by the framework. When a remote device initiates a connection, a confirmation dialog appears and, on acceptance, the connection is logged with the local and remote IP addresses.

## Using the demo UI

| Control | Function |
|---------|----------|
| **SSID** | SSID passed to `Start(ssid, passphrase)` |
| **Passphrase** | Passphrase passed to `Start` |
| **Start / Stop** | Starts or stops the Soft AP |
| **Get IP Settings** | Reads the Soft AP's IP configuration and logs it |
| **Set IP Settings** | Applies a static configuration (`192.168.2.10` / `255.255.255.0` / `192.168.2.1`) |
| **Reset IP Settings** | Resets the Soft AP's IP configuration back to the framework defaults |
| **Log** | Lifecycle events, connection events, IP addresses, and error codes |

## Behavioural notes

- **SSID and passphrase as reported.** `OnStarted` queries `GetSsid` and `GetPassphrase` and logs the strings returned by the framework. This is useful for confirming that the framework accepted the values supplied to `Start`, especially when it may adjust them for compatibility reasons.
- **Device acceptance.** `OnDeviceAccept` shows a native Yes/No message box; the device is accepted only when the user answers Yes. This matches the reference sample exactly.
- **Connection logging.** `OnDeviceConnected`, `OnDeviceDisconnected`, and `OnDeviceConnectError` each write one or more log lines. On successful connections, the framework-provided `LocalAddress` and `RemoteAddress` are logged.
- **Static IP configuration.** `Set IP Settings` uses the exact address / mask / gateway strings from the reference sample. `Reset IP Settings` calls `ResetIpSettings` and logs an error on failure.
- **Shutdown.** `Stop` is called in `OnDestroy`, wrapped in try/catch, matching the reference `FormClosing` handler.

## Project structure

WiFiDirectSoftAP/
├── README.md
├── Scripts/
│ ├── WiFiDirectSoftAPSceneBuilder.cs # Editor: Tools → WiFiDirectSoftAP → Build Scene
│ └── WiFiDirectSoftAPController.cs # Runtime: demo logic and UI shims
